# Release checklist

- Add an OSS license.
- Keep the full test suite green.
- Document the YAML format and provide copy-paste MCP host configuration.
- Add IT service management, CRM/support, and procurement example demos.
- Report configuration errors with useful YAML paths and messages.
- Add a deterministic state-reset command for demo runs.
- Choose the package name and publish an installable release to PyPI.
- Run the official MCP server conformance tests.
